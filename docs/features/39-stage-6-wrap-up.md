# 39 (6단계) 6단계 마무리: 남은 계획 정리와 완료 표기

## 배경과 목표
6단계(확정 이벤트와 배포)는 33~38로 기능이 다 들어왔다. 37·38 문서는 남은 일로 "C++ 빌드 기반 이미지를 GHCR에 올리고 CI를 그 안에서 돌리기"와 "CI에 release 빌드를 더할지 정하기"를 적었다. 이 PR은 둘을 하지 않기로 한 결정을 남기고, 작업 규칙 문서(CLAUDE.md)에 6단계 완료를 적는다.

## 고민한 선택지와 결정
| 주제 | 선택지 | 결정 |
|---|---|---|
| C++ 빌드 기반 이미지 | GHCR에 게시하고 CI를 그 안에서 / 지금 방식(버전 고정 + vcpkg 바이너리 캐시) | 지금 방식. 외부 레지스트리에 이미지를 게시하지 않는다. 러너 이미지의 변화는 이슈 001~009에서 한 고정과 캐시로 다뤄 왔다 |
| CI의 release 빌드 | 매트릭스에 release 추가 / 두지 않음 | 두지 않는다. release 빌드는 이미지를 만들 때마다 돈다. 이번 단계 끝에 전체 테스트가 release에서도 통과하는 것을 로컬에서 확인했다 |

## 구현
- `CLAUDE.md`: 단계 목록에 6단계 완료(Outbox, EventWorker, 조회 모델, compose Kafka, 통계 API, 컨테이너 이미지, K3s, 설계 노트 08). "다음"은 7단계부터
- 이슈 015의 재발 방지를 위 결정에 맞게 고쳤다

## 검증
- 로컬: release 프리셋(`-O2`)으로 전체를 빌드했고, 테스트 237개가 모두 통과했다.
- 문서만 바뀐다.
