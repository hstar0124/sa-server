# 피처 문서

피처 브랜치 하나에 문서 하나. 이 글이 그 피처 PR의 본문이기도 하다(먼저 쓰고 PR에 붙인다). 번호는 병합 순서다.

| # | 피처 | 단계 | 릴리스 |
|---|---|---|---|
| [01](01-repo-tooling.md) | 저장소 도구: 스타일·정적 분석 정책, CMake 프리셋, vcpkg, CI | 0 | |
| [02](02-design-docs.md) | 설계 문서 v1.0, ADR-0001~0008, 설계 노트 01~05, 작업 규칙 | 0 | |
| [03](03-contracts.md) | Protobuf 계약: game / backend / events / internal 네 패키지 | 0 | |
| [04](04-cpp-common.md) | C++ 공통: 강타입 ID, 프레이밍, 설정, HMAC, 인스턴스 ID, lease, 루트 CMake | 0 | |

## 형식

```
# NN <단계> <피처 제목: 결과 중심 한 문장>
## 배경과 목표        왜 지금 이것인가, 완료 조건
## 고민한 선택지와 결정  표(선택지·장점·단점·판단). 설계 변경이면 ADR 링크
## 구현              어느 모듈에 어떤 타입·테이블·메시지·설정 키가 생겼나
## 만난 문제          docs/issues/ 링크와 한 줄씩
## 검증              테스트 수(전후), ASan, tidy, e2e, 측정(보고서 링크)
## 남긴 것           다음으로 넘긴 항목, 보류한 결정
```
