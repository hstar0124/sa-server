# 63 설계 노트 12에 계보와 다음 단계: 옛 설계 노트에서 빠졌던 내용

## 배경과 목표
옛 저장소의 설계 노트 "한 지도에 몇 명까지"는 세 부분이었다.
- 이 프로젝트가 한 조치
- 다른 연구와 게임이 같은 문제를 어떻게 풀었는지(계보)
- 다음 단계의 방향

8c를 옮기며 첫 부분만 새 설계 노트 12에 들어가고 나머지 둘이 빠졌다. 옛 저장소를 정리하기 전에 그 둘을 옮긴다. 이로써 옛 저장소에서 옮길 것이 남지 않는다.

## 고민한 선택지와 결정
| 주제 | 선택지 | 결정 |
|---|---|---|
| 둘 곳 | 새 설계 노트 / 설계 노트 12에 절로 | 12에 절로. 같은 문제의 앞뒤라 한 글로 읽히는 편이 낫다 |
| 옛 수치 | 그대로 / 빼기 | 뺀다. 옛 저장소에서 잰 값이라 이 저장소의 측정이 아니다. 이 저장소의 숫자는 보고서 04에 있다 |
| 사례의 숫자 | 옛 노트 그대로 / 출처가 분명한 것만 | 분명한 것만. 논문(Donnybrook의 900명)과 공인 기록(Planetside 2의 1,158명)은 남기고, 출처를 다시 확인하지 못한 게임별 인원은 "수백 명"으로 묶었다 |
