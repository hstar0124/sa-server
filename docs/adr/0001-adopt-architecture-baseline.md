# ADR-0001: Server_Architecture.md v1.0을 설계 기준으로 채택

- 상태: Accepted
- 날짜: 2026-10-12

## 맥락
`docs/Server_Architecture.md`(v1.0, 2026-10-08)는 구현 전 설계 문서다. 불변 조건(부록 B), 멱등성·조건부 UPDATE(10~11절), owner_epoch·lease fencing(14절), Outbox/Inbox(12절)는 검토 결과 수정 없이 채택 가능하다. 반면 장비 전제(17절)와 구현 순서(20절) 일부는 실제 장비와 포트폴리오 목적에 맞게 조정이 필요하다.

## 결정
- 문서의 **불변 조건, 데이터 소유권 표(5절), 트랜잭션 규칙, fencing 규칙, 검증 시나리오(21절)**를 구현 사양으로 채택한다.
- 문서와 ADR이 충돌하면 ADR이 우선한다. 문서 본문은 구현 완료 후 실측값으로 갱신한다.
- 조정 사항은 각각 별도 ADR(0002~0008)로 기록한다.

## 결과
- 설계의 "왜"는 문서에, "무엇을 바꿨나"는 ADR에 남아 리뷰어가 추적할 수 있다.
- 문서를 수시로 고치지 않으므로 문서와 코드가 어긋날 위험이 있다. 각 단계 완료 시 문서 갱신을 완료 조건에 포함한다.
