# ADR-0006: 시드 기반 봇 클라이언트를 첫 클라이언트로

- 상태: Accepted
- 날짜: 2026-10-12

## 맥락
문서는 "두 클라이언트 시연"을 완료 조건으로 두지만 클라이언트 구현 계획이 없다. Unity/Unreal 클라이언트는 범위를 크게 넘는다. 부하 생성기(`tools/loadgen`)는 10단계에 있다.

## 결정
1. `tools/loadgen`(C++23, Gateway와 같은 프레이밍·계약 사용)을 **2단계에 만들고 첫 클라이언트로 쓴다.** 시연·테스트·부하 생성·정합성 검증을 모두 담당한다.
2. **모든 무작위성은 시드에서 나온다.** 실행마다 시드를 로그에 남기고, 같은 시드는 같은 입력 시퀀스를 재생한다.
3. 봇은 **가중치 상태 머신**으로 역할을 수행한다: Wanderer(배회), Fighter(몬스터 추적·전투), Looter(드롭 획득), Trader(거래), Flapper(접속 끊고 재접속). 역할 비율·인원·지역은 **프로파일(TOML)**로 준다. 21.2절의 분산 이동·밀집 전투·경제 집중은 프로파일 교체로 재현한다.
4. 봇은 서버 응답을 자기 기대값(보유 아이템, 잔액, 위치 범위)과 비교해 **불일치를 기록**한다. 봇이 정합성 검증기다.
5. 시각 확인은 **2D 웹 뷰어**(Canvas, WebSocket 어댑터 경유)로 한다. 2단계에 최소형, 이후 필요한 만큼만.

## 결과
- 게임 클라이언트 없이 모든 단계를 자동 검증한다. 시연 영상은 봇 + 뷰어 + Grafana로 만든다.
- 봇이 서버와 같은 저장소·계약을 쓰므로 프로토콜 변경이 즉시 봇 빌드에 반영된다.
