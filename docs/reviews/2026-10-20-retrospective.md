# 2026-10-20 회고 리뷰: 0~5단계까지 옮긴 코드

## 왜 했나
이 저장소는 먼저 만든 이력을 피처 단위로 다시 쌓고 있다. 21번째 피처까지 커밋마다 빌드, clang-tidy, ASan·UBSan, 통합 테스트, end-to-end를 돌렸다. 하지만 "잘 옮겨졌는가"는 봤어도 "잘 짜였는가"는 피처마다 체계적으로 보지 않았다. 옮기는 동안 이슈 011~013 같은 결함이 연달아 나오자, 이미 옮긴 코드 전체를 한 번 리뷰하기로 했다.

## 방법
- 영역을 다섯으로 나눠 리뷰어 다섯이 동시에 읽었다. 진행 중이던 23의 변경분, C++ 공통·Gateway, Zone, Backend·마이그레이션, 봇·뷰어·스크립트·CI·계약이다. 대상은 23 브랜치 끝(`62c4613`)의 읽기 전용 사본이다.
- 기준은 CLAUDE.md의 코드 규칙과 정합성·동시성·보안이다. 스타일 지적은 제외했다.
- 리뷰어의 지적은 그대로 믿지 않는다. 고치기 전에 해당 코드 경로를 직접 읽어 확인한다. 아래 "확인" 열의 ✔는 이 문서를 쓸 때 이미 확인한 것이다. 나머지는 고치는 PR에서 확인하고, 사실이 아니면 그 PR에 적고 닫는다.
